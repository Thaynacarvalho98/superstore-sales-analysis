# 📊 Superstore Sales Analysis

Data analysis project developed with **Python** and **Tableau Public** using the Global Superstore dataset.

## 📌 Project Overview

This project explores sales, profit, shipping costs, discounts, and customer segments through data cleaning, exploratory data analysis (EDA), and interactive dashboards.

## 🛠 Technologies

- Python
- Pandas
- Matplotlib
- Tableau Public

## 📈 Dashboards

- Sales and Profit Over Time
- Sales by Segment & Profit by Category
- Top 10 Countries, Cities by Sales and Profit
- Average Profit by Discount & Average Shipping Cost

## 🔍 Key Insights

- Sales and profit increased every year.
- Technology is the most profitable category.
- Consumer is the segment with the highest sales.
- The United States leads total sales.
- High discounts reduce profitability.
- Faster shipping methods have higher average shipping costs.
